# 🎵 Playliyy

A lightweight, client-side web application built with **HTML, CSS, and JavaScript** that allows users to fetch their YouTube or Spotify playlists and download them in manageable **chunks** for offline listening. 

Perfect for saving data, organizing long tracks, and preparing media for offline devices!

---

## 🚀 Features

* **Dual Platform Support:** Fetch playlist data from both YouTube and Spotify.
* **Chunked Downloading:** Split massive playlists into custom-sized batches/chunks to avoid browser crashes or network timeouts.
* **Offline Ready:** Formats downloaded audio for seamless local playback on any media player.
* **Pure Frontend:** Built using clean HTML, CSS, and Vanilla JavaScript with minimal dependencies.
* **Responsive UI:** A modern, clean interface designed to work smoothly on both desktop and mobile screens.

---

## 🛠️ Tech Stack

* **HTML5:** Structured semantic markup.
* **CSS3:** Custom styling with a modern dark/light theme and responsive grid layouts.
* **JavaScript (ES6+):** Async playlist fetching, DOM manipulation, and download stream handling.
